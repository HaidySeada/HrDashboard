# HR & Workforce Analytics Dashboard

## Project Overview

This project presents an interactive Power BI dashboard designed to analyze HR data across SEKEM Group companies, providing insights into workforce demographics, employee distribution, employment arrangements, payroll payment methods, and historical hiring trends.

The dashboard applies data cleaning, data transformation, data modeling, DAX calculations, and interactive data visualization to transform raw HR records into meaningful insights that support workforce analysis and data-driven decision-making.

## Objectives

- Analyze workforce size and employee distribution across SEKEM Group companies.
- Explore workforce demographics, including gender distribution.
- Examine employee allocation across locations, including Farm and HQ.
- Compare full-time and part-time employment arrangements.
- Analyze payroll payment methods, including bank transfers and cash.
- Investigate historical workforce and hiring trends.
- Identify data quality issues and opportunities to improve HR reporting.
- Provide actionable insights to support workforce planning and operational efficiency.

## Tools & Technologies

- Microsoft Power BI
- Power Query (M)
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Cleaning & Transformation
- Interactive Data Visualization

## Project Workflow

1. **Data Preparation:** Import and inspect the available HR dataset.
2. **Data Cleaning:** Identify and address missing values, inconsistent categories, and data quality issues.
3. **Data Transformation:** Use Power Query to clean, standardize, and prepare the data for analysis.
4. **Data Modeling:** Establish relationships between relevant tables to support accurate and consistent reporting.
5. **KPI Development:** Create DAX measures for workforce headcount, gender distribution, and other relevant HR metrics.
6. **Workforce Analysis:** Examine employee demographics, company distribution, locations, and employment types.
7. **Payroll Analysis:** Analyze the distribution of employees by payment method.
8. **Historical Trend Analysis:** Explore workforce patterns and hiring trends over time.
9. **Dashboard Development:** Build interactive Power BI visualizations with dynamic slicers and filters.
10. **Insights & Recommendations:** Identify opportunities for HR process improvement, workforce planning, and data quality governance.
